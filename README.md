# 404

Juego multijugador en línea hecho con Godot 4.7 y GDScript.

## Cómo empezar

1. Instala [Godot 4.7](https://godotengine.org/download/) (versión estándar, no .NET).
2. Clona el repositorio:
   `git clone git@github.com:MiguelT18/404-game.git`
3. En Godot, elige **Importar** y selecciona `project.godot`.
4. Pulsa **F5** para ejecutar el juego.

Haz commit de los archivos `.uid` que genera Godot: guardan las referencias entre recursos.
